

# Curso de formación en Symfony

Material de apoyo utilizado durante mis diversas intervenciones en escuelas y programas de formación. 

El curso está diseñado para introducir a principiantes en el framework, pero deben poseer ya bases correctas en PHP y en desarrollo web. El curso se extiende de 4 a 5 días para la parte básica, y hasta varias semanas para las secciones "avanzada" y "proyecto".

### Índice
  - *Exercises-basic* : Ejercicios prácticos de introducción (Controlador, Enrutamiento, Twig, Entidad, Relación, Formulario)
    - [Instalación](./exercises-basic/00-exercise-installation.md)     
    - [Controlador](./exercises-basic/01-exercise-controller.md)     
    - [Twig](./exercises-basic/02-exercise-twig.md)     
    - [Entidad](./exercises-basic/03-exercise-entity.md)     
    - [Formulario](./exercises-basic/04-exercise-form.md)     
    - [Formulario Twig](./exercises-basic/05-exercise-twig-form.md)     
    - [CRUD](./exercises-basic/06-exercise-crud.md)     
    - [Relación de Entidades](./exercises-basic/07-exercise-entity-relations.md)     
  - *Exercises-advanced* : Ejercicios avanzados específicos (FosUserBundle, carga de archivos, EventListener, Command)
    - [Carga de Imágenes](./exercises-advanced/02-image-upload.md)
    - [Event Dispatcher](./exercises-advanced/03-event-dispatcher.md)
    - [Comando](./exercises-advanced/04-command.md)
    - [Evento Doctrine](./exercises-advanced/05-event-doctrine.md)

  - *Exercises-project* : Enunciados para mini proyectos 
    - [Blog](./exercises-project/blog) : Creación de un blog con una sección de administración
    - [Búsqueda](./exercises-project/search) : Creación de una búsqueda por filtros para comprender el funcionamiento de consultas SQL complejas 
  - *Projects-sample* : Enlaces a los repositorios git de proyectos de ejemplo
  - *Presentation* : Diapositivas de presentación del framework
  - *Symfony Download* : .zip con un proyecto Symfony básico, en caso de problemas de red
